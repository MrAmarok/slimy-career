Paramètres de recherche

          
Ce qui est cherché quand tu cliques sur « Chercher des offres ».

        

        

          
Où chercher

          
Villes, régions ou pays. Chaque recherche est lancée dans chaque zone. Entrée pour ajouter.

          

          

            
            
          

        

        

          
Quoi chercher

          
Recherches complètes, envoyées telles quelles aux sites. Chaque recherche devient un tag sur les offres trouvées.

          

          
Recherches larges : chaque tag et chaque compétence est cherché séparément, précédé du type de contrat (« stage devops », « stage python »…).

          

            
          

          
          

          
          

        

        

          
Catégories automatiques

          
Une offre entre dans une catégorie si son titre contient un mot-clé, ou si sa description en contient au moins 3.

          

          

        

        

          
Compétences détectées

          
Repérées automatiquement dans les descriptions des offres.
